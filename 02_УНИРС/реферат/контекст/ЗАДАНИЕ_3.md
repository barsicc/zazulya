# Авторский комплект. 2.3. Снижение плотности водой и нефтью

**Цель.** Дать параметрический ответ и отдельно численную подстановку. Ориентир — 1,75–2,25 страницы по [плану](../ПЛАН.md), обозначения по [стандарту текста](../СТАНДАРТ_ТЕКСТА.md).

**Происхождение данных.** Преподавателем заданы $V_0=200$ м³, $\Delta\rho=200$ кг/м³, плотность нефти $\rho_\mathrm{н}=825$ кг/м³. Для пресной воды $\rho_\mathrm{в}=1000$ кг/м³ принято по методике. Начальная плотность $\rho_0$ и исходная объёмная доля нефти $\varphi_0$ в условии отсутствуют. Для отдельной партии принят условный сценарий: $\rho_0=1600$ кг/м³ по конечной плотности № 1, $\varphi_0=0$ (0 % об.), $\rho_\mathrm{к}=1400$ кг/м³ следует из снижения на 200 кг/м³. [1, с. 12–13, 40, 43 PDF] · [Проверенные условия](../../задания/ВАРИАНТ_07.md) · [Журнал решений](../../DECISIONS.md)

1. Исходная партия целиком сохраняется, объёмы складываются. Для воды и нефти отдельно из баланса § 1.4 получите $\rho_\mathrm{к}=\rho_0-\Delta\rho$ и $V_\mathrm{д}=V_0\Delta\rho/(\rho_0-\Delta\rho-\rho_\mathrm{д})$. Конечное решение при положительном снижении требует $\rho_\mathrm{к}>\rho_\mathrm{д}$. Отсюда для воды $\rho_0>1200$ кг/м³ и для нефти $\rho_0>1025$ кг/м³. При приближении к порогу справа объём стремится к бесконечности. На пороге и ниже заданное снижение недостижимо конечной добавкой. [1, с. 12–13 PDF, формулы (25)–(28) и пример 3, с. 39–40 PDF, формулы (99), (102)] · [2, с. 477–478 PDF]
2. Нефтесодержание отнесите к конечному объёму: $\varphi_\mathrm{к}^{(\mathrm{в})}=\varphi_0V_0/(V_0+V_\mathrm{в})$ и $\varphi_\mathrm{к}^{(\mathrm{н})}=(\varphi_0V_0+V_\mathrm{н})/(V_0+V_\mathrm{н})$. Для процентов умножьте долю на 100. Для исходной и добавленной нефти принята одна плотность. Для утяжелённого раствора $0\le\varphi_0<1$, $\rho_0>\rho_\mathrm{н}\varphi_0$ для положительной массы ненефтяной части. [Проверенный лист](../../расчеты/ЗАДАНИЕ_3.md)
3. Под отдельным подзаголовком покажите две подстановки, вычислите нефтесодержание и кратко сверьте $m_\mathrm{к}/V_\mathrm{к}=1400$ кг/м³, где $m_\mathrm{к}=\rho_0V_0+\rho_\mathrm{д}V_\mathrm{д}$. Проверку выполните на точных значениях. [Проверенный лист](../../расчеты/ЗАДАНИЕ_3.md)
