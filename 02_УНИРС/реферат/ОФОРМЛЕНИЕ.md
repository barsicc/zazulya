# Предварительное оформление Word

Параметры приняты оркестратором для подготовки реферата. Требования кафедры к оформлению ещё не подтверждены. При получении образца скорректируйте стили, параметры страницы и титульный блок в одном шаблоне Word.

| Элемент | Настройка |
| --- | --- |
| Страница | А4, книжная ориентация |
| Поля | Левое 30 мм, правое 15 мм, верхнее и нижнее по 20 мм |
| Основной текст | Times New Roman, 14 пт, межстрочный интервал 1,5, по ширине |
| Абзац основного текста | Отступ первой строки 1,25 см |
| Заголовки | Встроенные стили Word, уровень соответствует оглавлению. Заголовок удерживается со следующим абзацем |
| Таблицы | Заголовок над таблицей, тонкие линии, единицы в заголовке или у показателя. Заголовки повторяются при переносе длинной таблицы |
| Иллюстрации | Читаемые подписи и линии при печати в оттенках серого. Название под рисунком |
| Формулы | Редактируемые объекты Word в формате OMML, крупные выражения вынесены в отдельные строки |
| Нумерация объектов | Три сквозных ряда отдельно для формул, таблиц и рисунков. Номер формулы в круглых скобках возле формулы |
| Оглавление | Автоматическое поле Word, с номерами страниц из стилей заголовков |
| Нумерация страниц | Сквозная, полем PAGE. Предварительная настройка скрывает номер на титуле и учитывает титул в подсчёте |

## Титульный лист

Включите официальное название университета, кафедру, дисциплину, тему, вариант № 7, группу РТ-23-12, реквизит «Выполнил(а) — [ФИО студента]», реквизит «Проверил — В. П. Зозуля», город и год. Заполняемый реквизит заменяется реальными сведениями в экземпляре для сдачи. Публичная ветка использует заполняемый реквизит.

## Сборка при подготовке документа

1. Храните текст глав в Markdown по порядку из [ПЛАН.md](ПЛАН.md). Оглавление располагается после титульного листа и перед введением. Заголовки разделов размечайте уровнями Markdown, таблицы и формулы оформляйте по [СТАНДАРТУ_ТЕКСТА.md](СТАНДАРТ_ТЕКСТА.md).
2. Храните авторскую графику в каталоге «иллюстрации». Шаблон Word и файлы технической сборки размещайте в каталоге «сборка».
3. Собирайте главы через Pandoc с `--reference-doc`, `--toc` и `--resource-path` по маршруту из README. Учитывайте, что обычное `--toc` вставляет поле перед основным содержимым. При сборке обеспечьте требуемый порядок разделом Word с отдельным титулом и полем оглавления перед введением. При получении образца измените только настройки шаблона и уровни оглавления.
4. В редакторе обновите поле оглавления с номерами страниц и проверьте после последнего изменения текста. Проверьте поля PAGE, вид титула, переносы таблиц, доступность формул как объектов, нумерацию и ссылки на рисунки. Для просмотра страниц можно экспортировать рабочую копию в PDF. Подтвердите фактическую пагинацию и читаемость чёрно-белого варианта. [Техническая проба этапов 1–2](../README.md#подход-к-сборке-на-следующих-этапах)
