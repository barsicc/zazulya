# Независимое решение варианта № 7

При повышении плотности до 1600 кг/м³ требуется **37 903,23 кг Fe₂O₃** или **40 094,34 кг барита**. Объём раствора увеличивается соответственно на **8,0645 м³** или **9,4340 м³**. Плотность водного раствора с массовой долей бентонита 7 % составляет **1043,84 кг/м³**. В условном сценарии 1600 → 1400 кг/м³ требуется **100 м³ воды** или **69,5652 м³ нефти**. При нулевой исходной доле нефти второй способ даёт **25,8065 % нефти по объёму**.

## Исходные данные и расчётная модель

С. 43 пособия «Расчеты при измерении плотности буровых растворов» задаёт три задачи. В строке 7 для задачи № 1 указаны 1350 → 1600 кг/м³ и оксид железа, объединённая ячейка для вариантов 7–8. Для искусственного оксида Fe₂O₃ взяты 4700 кг/м³ с. 8, для барита — расчётные 4250 кг/м³ с. 11. Массовая доля бентонита равна номеру варианта в процентах. Базис готовой смеси 100 кг выбран для удобства, плотность бентонита 2500 кг/м³ задана на с. 43, пресной воды 1000 кг/м³ использована на с. 12. Для задачи № 3 заданы снижение на 200 кг/м³, начальный объём 200 м³ и плотность добавляемой нефти 825 кг/м³. Исходная плотность 1600 кг/м³ и нулевая начальная объёмная доля нефти приняты для численного сценария. [Машиночитаемые исходные данные](../задания/ВАРИАНТ_07.json)

Модель предполагает сохранение массы и аддитивность объёмов. Начальный раствор целиком остаётся в системе, а утяжелитель или разбавитель добавляется к нему. При заданной целевой плотности `ρ_f` и плотности добавки `ρ_a` непосредственно решается линейная система для `V_a, V_f, M_a, M_f`.

```text
M_f − M_a    = M₀ = ρ₀ V₀     [кг]
V_f − V_a    = V₀             [м³]
M_a − ρ_a V_a = 0             [кг]
M_f − ρ_f V_f = 0             [кг]
```

Плотность проверяется делением найденных массы и объёма в кг/м³. В ручном исключении из этих строк следует `(ρ_a − ρ_f) V_a = (ρ_f − ρ₀) V₀`. Обе части имеют размерность массы. Объём добавки имеет размерность м³, поскольку разность плотностей в знаменателе выражена в кг/м³. Проценты рассчитываются как отношения одноимённых величин, умноженные на 100. Скрипт решает полные системы методом Гаусса — Жордана над рациональными числами и проверяет балансы точными равенствами. Десятичные значения округлены только при представлении.

## 1. Утяжеление оксидом железа и баритом

Начальный объём `V₀ = 100 м³`, начальная плотность `ρ₀ = 1350 кг/м³` и начальная масса `M₀ = 135 000 кг`. После исключения остальных неизвестных для Fe₂O₃ получаем `3100 V_a = 25 000 кг`, для барита — `2650 V_a = 25 000 кг`. Коэффициенты при объёмах выражены в кг/м³.

| Величина | Искусственный Fe₂O₃ | Барит |
| --- | ---: | ---: |
| Увеличение объёма, м³ | 250/31 ≈ 8,0645 | 500/53 ≈ 9,4340 |
| Масса утяжелителя, кг | 1 175 000/31 ≈ 37 903,23 | 2 125 000/53 ≈ 40 094,34 |
| Конечный объём, м³ | 3350/31 ≈ 108,0645 | 5800/53 ≈ 109,4340 |
| Конечная масса, кг | 5 360 000/31 ≈ 172 903,23 | 9 280 000/53 ≈ 175 094,34 |
| Конечная плотность, кг/м³ | 5 360 000/3350 = 1600 | 9 280 000/5800 = 1600 |

Масса Fe₂O₃ меньше на `3 600 000/1643 кг ≈ 2191,11 кг`. Экономия относительно массы барита равна `100 × (3 600 000/1643) / (2 125 000/53) = 2880/527 % ≈ 5,4649 %`. Прирост объёма при Fe₂O₃ меньше на `2250/1643 м³ ≈ 1,3694 м³`, или на `450/31 % ≈ 14,5161 %` от прироста объёма при барите.

Плотность смеси является взвешенным по объёму средним. Для обоих материалов `1350 < 1600 < ρ_a`, поэтому массы и объёмы добавок положительны. При положительном увеличении плотности и фиксированной цели больший разрыв `ρ_a − ρ_f` уменьшает объём добавки. Уравнение `M_a = ρ_f V_a + (ρ_f − ρ₀) V₀` показывает, почему в этом случае уменьшается также масса добавки. При приближении целевой плотности к плотности утяжелителя требуемый объём растёт без предела.

Общие формулы (21)–(22) на с. 11 пособия согласуются с прямым балансом. Для приведённого там частного случая `V₀ = 10 м³` коэффициент массы должен быть `10 × 4250 = 42 500` в числителе. В (17) напечатано 4250, а в подстановке примера 1 на с. 12 напечатано 425 000. Напечатанный ответ примера 1, 9444 кг, согласуется с общим балансом и коэффициентом 42 500 при округлении до целых килограммов.

## 2. Плотность водного раствора с бентонитом

Для масс и объёмов бентонита и воды решается система `M_b + M_w = 100 кг`, `M_b = (7/100) × 100 кг`, `M_b = ρ_b V_b`, `M_w = ρ_w V_w`, `V_f = V_b + V_w`. В скрипте массы подставляются через плотности до исключения объёмов.

| Компонент | Масса, кг | Объём, м³ |
| --- | ---: | ---: |
| Бентонит | 7 | 7/2500 = 0,0028 |
| Вода | 93 | 93/1000 = 0,0930 |
| Смесь | 100 | 479/5000 = 0,0958 |

Отсюда `ρ_f = 100 / (479/5000) = 500 000/479 кг/м³ ≈ 1043,84 кг/м³`. Обе массы положительны и дают в сумме 100 кг. Массовая доля бентонита точно равна 7 %, его объёмная доля составляет `1400/479 % ≈ 2,9228 %`. Значение плотности лежит между 1000 и 2500 кг/м³. При нулевой массовой доле бентонита модель даёт плотность воды, при единичной — плотность бентонита. Построение баланса соответствует примеру 2 на с. 12 пособия.

## 3. Разбавление для снижения плотности

Численный сценарий использует `V₀ = 200 м³`, `ρ₀ = 1600 кг/м³`, `ρ_f = 1400 кг/м³`, `M₀ = 320 000 кг`. Вода и нефть рассматриваются как две альтернативы. Исключение неизвестных даёт уравнение `(1400 − ρ_a) V_a = 40 000 кг`. Для воды разность плотностей равна 400 кг/м³, для нефти — 575 кг/м³.

| Величина | Вода | Нефть |
| --- | ---: | ---: |
| Объём добавки, м³ | 100 | 1600/23 ≈ 69,5652 |
| Масса добавки, кг | 100 000 | 1 320 000/23 ≈ 57 391,30 |
| Конечный объём, м³ | 300 | 6200/23 ≈ 269,5652 |
| Конечная масса, кг | 420 000 | 8 680 000/23 ≈ 377 391,30 |
| Конечная плотность, кг/м³ | 420 000/300 = 1400 | 8 680 000/6200 = 1400 |
| Объёмная доля нефти при нулевой начальной доле, % | 0 | 800/31 ≈ 25,8065 |

Нефти требуется на `700/23 м³ ≈ 30,4348 м³` меньше объёма воды. Экономия относительно объёма воды равна `100 × (700/23) / 100 = 700/23 % ≈ 30,4348 %`. Знаменатель доли нефти — конечный объём раствора, как в примере 3 на с. 13 пособия. При нулевой исходной доле `100 × (1600/23) / (6200/23) = 800/31 %`.

### Зависимость от начальной плотности и состава

Пусть `r` — начальная плотность, `δ = 200 кг/м³` — требуемое снижение, `f₀` — исходная объёмная доля нефти в долях единицы. Тогда `ρ_f = r − δ`, а исходный объём нефти равен `f₀ V₀`. При положительной конечной добавке плотностью `ρ_a` получаем

```text
V_a = V₀ δ / (r − δ − ρ_a)
V_a / (V₀ + V_a) = δ / (r − ρ_a)
```

Оба выражения применимы при `r > ρ_a + δ`. При `r = ρ_a + δ` смесь стремится к цели по мере неограниченного роста объёма добавки. При `r < ρ_a + δ` цель недостижима этим разбавителем. С водой конечное решение существует при `r > 1200 кг/м³`, с нефтью — при `r > 1025 кг/м³`. В интервале `1025 < r ≤ 1200 кг/м³` подходит только нефть. При `r ≤ 1025 кг/м³` обе альтернативы недостижимы. Если доступны обе, объём нефти меньше объёма воды из-за более низкой плотности. Относительная экономия составляет `(1000 − 825)/(r − δ − 825)` от объёма воды. При росте `r` для фиксированного снижения объёмы обеих добавок уменьшаются.

| Разбавитель | Итоговая объёмная доля нефти |
| --- | --- |
| Вода | `f₀ V₀ / (V₀ + V_w) = f₀ [1 − δ/(r − 1000)]` |
| Нефть | `(f₀ V₀ + V_o) / (V₀ + V_o) = f₀ + (1 − f₀) δ/(r − 825)` |

Для перевода в проценты доли умножаются на 100. При `r = 1600 кг/м³` они равны `2 f₀/3` при добавлении воды и `8/31 + 23 f₀/31` при добавлении нефти. При фиксированной исходной плотности `f₀` влияет на готовый состав, а необходимые объёмы добавок определяются балансами исходного раствора в целом. Физическая совместимость исходных данных требует `r − 825 f₀ > 0` при `0 ≤ f₀ < 1`, чтобы оставшаяся часть раствора имела положительную массу. При `f₀ = 1` исходный раствор целиком состоит из нефти плотностью 825 кг/м³ и положительное снижение плотности на 200 кг/м³ обоими заданными разбавителями недостижимо.
