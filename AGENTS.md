# Работа с репозиторием

Для УНИРС «Расчёты при измерении плотности бурового раствора» начните с [02_УНИРС/README.md](02_УНИРС/README.md) и [02_УНИРС/STATUS.md](02_УНИРС/STATUS.md). В этой области действуют правила [02_УНИРС/AGENTS.md](02_УНИРС/AGENTS.md).

Для подготовки к контрольным и экзаменам используйте навигацию в [README.md](README.md) и предметный порядок поиска в [CLAUDE.md](CLAUDE.md). Правила синхронизации веток в разделе «Режим КР» относятся к тому режиму. УНИРС ведётся в ветке `unirs-2026`, переходы между этапами и слияние согласовываются с оркестратором.

Сохраняйте лекционный PDF, конспекты, изображения и инструменты курса. Для дословных цитат и чисел сверяйтесь с первоисточником. Указывайте страницу PDF и, при необходимости, соответствующую печатную страницу книги.
