## ⭐ Ключевое (определения)
- **Реология** — отдел науки, изучающий деформацию всех форм вещества; реологические свойства растворов выводятся из **математических моделей** (точно не моделируются). (496)
- **Напряжение сдвига τ = F/A** (сила сопротивления скольжению слоёв; фунт/100 фут²); слой у стенки неподвижен. **Скорость сдвига γ = разность скоростей / расстояние, с⁻¹.** (497)
- **Ньютоновские жидкости** — τ ∝ γ (вода, спирт, лёгкие масла); **большинство буровых растворов — неньютоновские**. **Вязкость μ = τ/γ** (пуаз = дин·с/см²; сантипуаз = 0,01 П). У неньютоновских — **эффективная вязкость**, падает с ростом γ = **сдвиговое разжижение — «очень благоприятная характеристика»**: низкая вязкость в трубах и насадках, высокая в затрубье (вынос шлама). (497–498)
- **Режимы течения** (Рейнольдс, 1883): **ламинарный** (слои-цилиндры «как подзорная труба», скорость у стенки 0, в центре max; скорость сдвига max у стенки), **турбулентный** (хаотичный; профиль крутой у стенок, плоский в центре), **переходный**, **пробковый (поршневой)** — при сверхнизких скоростях, жидкость движется как твёрдое тело. **Re = VDρ/μ** (4); для ньютоновских: **ламинарный ≤ 2000, переходный 2000–4000, турбулентный ≥ 4000**. (498–503)
- **Непрерывность потока**: Q = const → **скорость обратно пропорциональна площади сечения**. (503–504)
- **Модель Ньютона: τ = μγ** (5) — прямая через начало координат. (504)
- **Модель Бингама (вязкопластичная): τ = τ₀ + μγ** (6); **предел текучести YP (τ₀)** — конечное напряжение для начала течения; **пластическая вязкость PV** — предельное (наименьшее) значение эффективной вязкости при γ → ∞ = наклон прямой. **PV — показатель размера, формы, распределения и количества твёрдой фазы и вязкости жидкой фазы; YP — мера электрических сил притяжения** в растворе. **Кажущаяся вязкость μэф = θ600/2** (7). Полимерные системы сильно отступают от Бингама. (505–506)
- **Степенная модель (псевдопластичная): τ = Kγⁿ** (8); **K — коэффициент консистентности** (≈ эффективной вязкости), **n — показатель нелинейности**: **n = 1 — ньютоновская; n > 1 — дилатантная (вязкость растёт с γ); 0 < n < 1 — псевдопластичная (буровые растворы, сдвиговое разжижение)**. Бингам плох при низких γ, степенная — не учитывает предел текучести; **реальные растворы — между Бингамом и степенной**. Различия моделей важны при **низких скоростях сдвига — критичных для очистки и удержания утяжелителя**. (506–508)
- **Табл. 1 (ротор–пружина R1–B1): 3 об/мин → 5,11 с⁻¹; 6 → 10,2; 100 → 170; 200 → 341; 300 → 511; 600 → 1022 с⁻¹** (γ = 1,703·об/мин). (510)
- **СНС** характеризует **тиксотропные** свойства; регистрируют через **10 с и 10 мин** (доп. 30 мин). **Прогрессирующее** СНС — сильно растёт со временем (нужно высокое давление для восстановления циркуляции); **хрупкое** — растёт мало, но вначале может быть выше. (511–512)

- Бессмысленно наращивать мощность на долоте в мягких породах, если скорость лимитирует время наращивания. Максимум мех. скорости ≠ минимум стоимости метра. (496, 517)
- **Свабирование и пульсации**: **большинство выбросов — при подъёме, поглощений — при спуске**. Допущение «закрытая колонна» (долото с насадками, обсадная с обратным клапаном) даёт давление ≥ истинного; «открытый конец» — обычно занижает. Если рассчитанное давление меньше давления разрушения геля — брать давление разрушения геля. **EMW при спуске > градиента ГРП → поглощение; EMW при подъёме < порового → приток.** (518–521)
