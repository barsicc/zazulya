# Правила работы над УНИРС

- При открытии новой сессии прочитайте [STATUS.md](STATUS.md), затем нужные для задачи файлы из [README.md](README.md). Существенные выводы и открытые вопросы фиксируйте в репозитории.
- Для условий используйте пособие преподавателя, для дополнительного обоснования — лекционный конспект. Числа, таблицы и формулы проверяйте по изображению страницы. Указывайте источник и страницу PDF.
- Различайте дословные цитаты, выводы из модели и предположения. Указывайте размерности в СИ. Массовые и объёмные доли обозначайте явно. Округляйте окончательный результат, сохраняя точность промежуточных вычислений.
- Для задания № 3 начальная плотность остаётся открытым вопросом. Сохраняйте вывод в параметрической форме. Значения 1600 и 1400 кг/м³ используйте только для явно обозначенного условного сценария.
- Храните результаты этапов в `unirs-2026`. Переходите к написанию реферата после утверждения оркестратором. Исходное пособие, полный текст извлечения и рендеры размещайте в `источники/локально/`, исключённом из Git. Публикация этих файлов или персональных данных в публичном репозитории требует отдельного разрешения.
- Обновляйте [STATUS.md](STATUS.md) после существенной работы, [DECISIONS.md](DECISIONS.md) после принятия или пересмотра решения и [SOURCES.md](SOURCES.md) при изменении состава источников.
