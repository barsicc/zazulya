# Авторский комплект. 2.2. Плотность бентонитового раствора

**Цель.** Найти плотность смеси по массовой доле бентонита. Ориентир — 1–1,25 страницы по [плану](../ПЛАН.md), обозначения по [стандарту текста](../СТАНДАРТ_ТЕКСТА.md).

**Данные.** Массовая доля по условию равна номеру варианта в процентах, $w_\mathrm{б}=0{,}07$. Плотность бентонита 2500 кг/м³ задана, плотность пресной воды 1000 кг/м³ принята по примеру 2. База — 100 кг готовой смеси. [1, с. 43, 12 PDF] · [Проверенные условия](../../задания/ВАРИАНТ_07.md)

1. Из § 1.4 возьмите $m_i=w_i m$, $V_i=m_i/\rho_i$. При аддитивности $\rho=1/[w_\mathrm{б}/\rho_\mathrm{б}+(1-w_\mathrm{б})/\rho_\mathrm{в}]$. Выведите формулу из баланса и покажите подстановку. [1, с. 12 PDF, пример 2] · [2, с. 471–472, 475–476 PDF] · [Проверенный лист](../../расчеты/ЗАДАНИЕ_2.md)
2. Сведите массы и объёмы компонентов в компактную таблицу. Бентонит 7,00 кг и 0,0028 м³, вода 93,00 кг и 0,0930 м³. Общий объём 0,0958 м³, плотность $500000/479\approx1043{,}84$ кг/м³. Для проверки $m_\mathrm{б}/m=0{,}07$ и $\rho(V_\mathrm{б}+V_\mathrm{в})=100$ кг по точному значению. [RESULTS.json, results.bentonite](../../расчеты/RESULTS.json)
3. По $\varphi_\mathrm{б}=V_\mathrm{б}/V$ получите 2,92 % об. при 7 % по массе. Плотность смеси лежит между плотностями компонентов. Вклад гидратации в изменение суммарного объёма модель опускает. Причину расхождения долей раскройте в анализе. [RESULTS.json](../../расчеты/RESULTS.json) · [2, с. 82–83 PDF]

**Готовность.** Обе доли однозначно названы, плотность получена из массы и общего объёма, СИ соблюдена. Здесь приготовили смесь из двух компонентов, в § 2.3 предстоит изменить готовый раствор.
