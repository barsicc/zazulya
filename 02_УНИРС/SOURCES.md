## Пособие преподавателя

В. П. Зозуля, О. К. Ангелопуло, Н. Е. Зозуля, В. В. Головин. *Расчеты при измерении плотности бурового раствора*. Учебное пособие. М., РГУ нефти и газа имени И. М. Губкина, 2026. Сведения сверяются по с. 1–3. Библиографическая строка на с. 3 указывает 65 с., фактический файл содержит 69 страниц. На с. 69 сохранилась строка с 2021 годом и направлением 21.03.01. Для идентификации экземпляра используются титульные данные с. 1–3 и SHA-256.

- Имя файла `Плотность_бурового_раствораРТ_23_12.pdf`.
- Локальный путь `источники/локально/Плотность_бурового_раствораРТ_23_12.pdf`.
- SHA-256 `61c5b8b567d11db268d6a6c8431e82e63704fee9ec31cac7e8830d1d42be9fb8`.
- В приложенном файле номера листов PDF и напечатанные номера совпадают. Условия трёх заданий находятся на с. 43, таблица вариантов — на с. 43–44.
- Текстовый слой годится для поиска, но теряет структуру дробей, индексы и границы объединённых ячеек. На с. 55–67 текстовый слой содержит только номера страниц. Полное извлечение с разметкой страниц хранится локально, отдельные файлы для всех 69 страниц находятся в `источники/локально/страницы/`. Для проверки содержания и критических мест используются рендеры страниц.

Навигация по экземпляру и проверенные выдержки доступны в ветке. [Указатель пособия](источники/УКАЗАТЕЛЬ_ПОСОБИЯ.md) · [Методика пособия](источники/МЕТОДИКА_ПОСОБИЯ.md) · [Условия](задания/УСЛОВИЯ.md)

В локальном каталоге сохранены сплошное извлечение `текст.txt`, файлы `страницы/01.txt`–`страницы/69.txt` и черновое OCR растровых страниц 55–67 в `ocr/` (Tesseract, модели `rus+eng`). OCR пригодно для поиска заголовков и терминов. Значения и структуру таблиц сверяйте по изображению PDF.

## Лекционный конспект

*Конспект лекций «Промывка скважин и буровые растворы»*, курс В. П. Зозули. Основной файл содержит 543 страницы PDF. Текст поделен на разделы, карта и постраничные конспекты используются для поиска. В ссылках фиксируйте раздел и страницу PDF. Старые навигационные файлы указывают смещение печатных номеров на +4. Визуальная проверка показала смещение +5 на с. 188 и 476–478 PDF. Печатный номер приводите только по изображению конкретной страницы.

Лекции служат дополнительным источником по приборам, компонентам раствора, технике расчётов и связи плотности с осложнениями. При расхождении чисел фиксируйте оба значения с контекстом их применения. [PDF лекций](../01_Лекции/Конспект_лекций_Зозуля_Промывка_скважин_и_буровые_растворы.pdf) · [Карта лекций по УНИРС](теория/КАРТА_ЛЕКЦИЙ.md)
