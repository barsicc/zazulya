Учебный пример с готовой смесью подтверждает базу в 100 кг и 1000 кг/м³ для пресной воды. [Вариант](../задания/ВАРИАНТ_07.md) · [Карта цитирования](../реферат/КАРТА_ЦИТИРОВАНИЯ.md)

Доля всей нефти относится к конечному объёму. [Комплект задания № 3](../реферат/контекст/ЗАДАНИЕ_3.md)

## Порядок написания после приёмки

1. Автор теории готовит главу 1 по четырём подразделам и согласует обозначения баланса с автором расчётов. Редактор проверяет опору на страницы лекций и подпись к рисунку 1.
2. Автор расчётов готовит § 2.1–2.3. При разделении между тремя авторами первый отвечает за общий заголовок главы, редактор сверяет обозначения, происхождение исходных величин и округление. Числа берутся из единого реестра.
3. Автор анализа работает по согласованным ответам, объясняет отличия трёх постановок и вставляет график с пояснением. Введение и заключение можно отдать одному автору. Он согласует цель с уже принятыми тезисами и выводами.
4. Редактор готовит титул и литературу, сверяет покрытие условий, затем собирает главы в указанном порядке. После обновления полей проверяет OMML, ссылки, оглавление, нумерацию и читаемость в PDF. [План](../реферат/ПЛАН.md) · [Оформление](../реферат/ОФОРМЛЕНИЕ.md)

## Риски и открытые вопросы

| Вопрос | Как учтён |
| --- | --- |
| Подтверждение преподавателем начальной плотности и исходного нефтесодержания в № 3 | Условный сценарий явно помечен. Если появятся данные, заменить только подстановку и зависимые выводы, сохранив модель |
| Образец титула, норматив оформления, объём и формат сдачи | Word-параметры предварительные и управляются шаблоном. ФИО в публичных материалах представлены заполняемым полем |
| Оглавление и разбиение на страницы | Проверить в итоговом редакторе, обновить поля, удержать формулы и таблицы в рассчитанных диапазонах. Уточнить фактический объём после пробной вёрстки |
| Точный перенос формул из источников с известными опечатками | Использовать общий баланс и проверенные пошаговые выводы. Для цитат обращаться к указанным страницам и сверять начертание |
| Практический выбор утяжелителя или разбавителя, риск поглощения | Выводы ограничены расчётным расходом и гидростатикой. Для практической оценки нужны свойства, состав и данные скважины |

**Готовность.** Материалов достаточно для начала написания по семи комплектам после приёмки этапа 3. Уточнения по заданию № 3 и оформлению можно внести по мере поступления, сохранив параметрическую постановку и управляемый шаблон.
