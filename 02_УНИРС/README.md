## Подход к сборке на следующих этапах

Вести главы в `реферат/` в Markdown с единой системой обозначений. Предварительная последовательность глав — титульный лист, введение, теория, три расчётные главы, заключение, литература. Утвердить структуру и шаблон перед написанием.

Собирать главы в заданном порядке Pandoc с `--reference-doc` для стилей, полей страницы и колонтитулов и с `--toc` для поля оглавления. Записывать формулы в синтаксисе TeX, который Pandoc преобразует в редактируемый OMML. Для колонтитулов при необходимости дополнить шаблон полем `PAGE` через python-docx. Путь к рисункам задавать через `--resource-path`. После сборки обновлять поля оглавления и проверить подписи, формулы, разрывы страниц, оформление титульного листа и нумерацию. PDF для визуальной сверки можно экспортировать через LibreOffice в облачной среде. Финальный DOCX можно открыть в браузере через Google Документы после выбора режима просмотра или импорта.

Техническая проба в текущей среде подтвердила, что Pandoc 3.1.11.1 сохраняет дробь как OMML, таблицу, рисунок и поля `TOC`/`PAGE`. LibreOffice экспортировал пробу в PDF с формулой и номерами страниц. Оглавление в этом экспорте осталось без записей, поэтому на этапе сборки потребуется отдельное обновление полей. Импорт и сохранение редактируемости формул через Google Документы подлежат проверке на черновике. Пробные файлы хранились во временном каталоге.
