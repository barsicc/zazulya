# zazulya — «Промывка скважин и буровые растворы» (проф. Зозуля В.П.)

Подготовка к контрольной/экзамену. Курс целиком = `01_Лекции/Конспект_лекций_…pdf` (543 стр., 16 разделов).

**Начать отсюда:**
- `ШПАРГАЛКА.md` — все перечни и числа на одной странице
- `ВОПРОСЫ.md` — 133 вопроса с ответами и страницами
- `ФОРМУЛЫ.md` — все формулы (Ф1–Ф79)
- `КАРТА.md` — разделы и предметный указатель «термин → стр.»
- `конспекты/` — по каждому разделу выжимка «⭐ Ключевое» + полный текст постранично
- `рисунки/` — картинки страниц с рисунками, таблицами и формулами
- `РЕШЕНИЕСМОТРИ/ОТВЕТЫ.md` — ответы во время КР
- Поиск: `tools/search.sh "фраза"` → раздел и страница с цитатой
