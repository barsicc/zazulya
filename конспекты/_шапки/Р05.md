## ⭐ Определения параметров (дословно)
- **Плотность ρ** — отношение массы бурового раствора к его объёму; приборы: **ареометр, пикнометр, рычажные весы**. (109)
- **Условная вязкость (УВ, с)** — величина, определяемая временем истечения из стандартной воронки определённого объёма бурового раствора; **косвенно характеризует гидравлическое сопротивление течению, т.е. подвижность**. Приборы: **ВБР-1, воронка Марша**. (112)
- **ДНС τ₀ (дПа)** — величина, косвенно характеризующая **прочностное сопротивление** бурового раствора течению. (115)
- **Пластическая (структурная) вязкость ηпл** — условная величина, показывающая **долю эффективной вязкости, которая возникает вследствие структурообразования в потоке**. (115)
- **Эффективная (кажущаяся) вязкость ηэф** — косвенно характеризует **вязкостное сопротивление** при определённой скорости сдвига. (115)
- **СНС** — приборы СНС-2, ВСН-3, FANN; (182) «мера минимального сдвигающего напряжения, необходимого для создания движения с проскальзыванием».
- **Показатель фильтрации Ф, см³** — объём дисперсионной среды, отфильтрованный за определённое время через бумажный фильтр ограниченной площади; **косвенно характеризует способность раствора отфильтровываться через стенки ствола**. Приборы: **ВМ-6, фильтр-пресс**; горизонтальная — пресс низкого давления. (120)
- **Концентрация посторонних твёрдых примесей Сп, %** — отношение количества всех грубодисперсных частиц к общему количеству раствора; **отстойник ОМ-2**; = **удвоенный объём осадка**. **Песок по АНИ** — частицы **> 74 мкм**, сито **200 меш**. (128)
- **Стабильность** — способность раствора сохранять плотность в течение времени; **показатель стабильности С = ρ₁ − ρ₂** (разность плотностей верхней и нижней частей после **24 ч**; цилиндр **ЦС-2, 720 см³**). **Показатель седиментации С = 100 − V, %** (цилиндр 100 см³, 24 ч). (130–131)
- **Концентрация коллоидных частиц Ск** — частицы **< 2 мкм**; характеризует активную составляющую твёрдой фазы; метод — **адсорбция метиленовой сини (МС)**: **1 г коллоидного бентонита адсорбирует 59 см³ 0,45 % МС**. (131)
- **Показатель минерализации М** — содержание водорастворимых солей, условно в эквиваленте NaCl. (136)
- **Стабильность эмульсии** — электростабильность (ЭУ, В); АНИ: (49 ± 3) °С; в водопроводной воде ЭУ ≤ 3 В. (171–172)
- **Выход раствора** — основной показатель качества (сортности) глин: **количество м³ глинистой суспензии с заданной вязкостью из 1 т глины**. (175)

## ⭐ Расчётные формулы
- ВСН-3, 600/300: **ηпл = φ₂ − φ₁ (3); τ₀ = 3(φ₁ − ηпл) (4)**; 400/200: **ηпл = 1,5(φ₂ − φ₁) (5); τ₀ = 3φ₁ − 2ηпл (6)**; **ηэф = A·φ₁/600 (7)**. (115)
- FANN: **ηпл = φ600 − φ300, сПз (8)**; **τ = (φ300 − ηпл)·4,8, дПа (9)** (в тексте PDF знак напечатан как «–», по смыслу ×4,8 — перевод фунт/100 фут² → дПа); **ηк = φ600/2, сПз (10)**. СНС FANN = максимум при 3 об/мин × 4,8 (10 с и 10 мин). (116, 119)
- СНС-2: θ₁,₁₀ = A·φ₁,₁₀ (11); ВСН-3: θ = k·φ (12) (k — СНС при угле 10). (117–118)
- Соль по реторте: Фсоли = 0,18·Фводы·(Cl⁻ мг/л)/300000 (20); концентрация соли, кг/м³ = 2,853·(Cl/10000)·(Фводы + Фсоли)·0,058 (21); частицы малой плотности КЧМП = 2,853·68,25·[D − 8,33(1 − Фсоли/100)] (22), D — фунт/галлон. (135–136)
- Сухой остаток: Pс.о. = (P − P₁)·10⁶/a, мг/л (23). Пересчёт: мг-экв/л = мл·N·1000/V; мг/л = мг-экв/л × экв. вес (табл. 2: Cl⁻ 35,45; CO₃²⁻ 30; HCO₃⁻ 61; SO₄²⁻ 48; Ca²⁺ 20,04; Mg²⁺ 12,15; Na⁺ 22,98; K⁺ 39,1). (137–138)
- Ca: X = V·N·1000/a (24); Y = X·Э (25). Mg: X = (V₁ − V)·N·1000/a (26). Cl⁻: X = V·N·1000/a (29), Э = 35,5. (146–148)
- **Известь: кг/м³ = 0,742·(Pm − Fw·Pf)**; фунт/баррель = 0,26·(Pm − Fw·Pf); Fw = % воды/100. (143)

## ⭐ Интерпретация щёлочности (стр. 140–143)
| Условие | Щёлочность | Состояние раствора |
|---|---|---|
| Pf = 0 | только HCO₃⁻ | нестабилен, трудно контролировать |
| Pf = Mf | только OH⁻ | стабилен, хороший |
| 2Pf = Mf | только CO₃²⁻ | нестабилен |
| 2Pf > Mf | OH⁻ + CO₃²⁻ | стабилен, хороший |
| 2Pf < Mf | CO₃²⁻ + HCO₃⁻ | нестабилен |
Вывод: **бикарбонат переводить в карбонат, карбонат удалять или переводить в гидроксид**. Бикарбонат не существует при гидроксиде. Карбонат удаляют кальцием (CaCO₃↓). Обработки: (1) Ca(HCO₃)₂ + Ca(OH)₂ = 2CaCO₃ + 2H₂O (Ca ≤ HCO₃); (2) Ca(HCO₃)₂ + 2NaOH = CaCO₃ + Na₂CO₃ + 2H₂O (Ca > HCO₃); (3) NaHCO₃ + Ca(OH)₂ = CaCO₃ + NaOH + H₂O (кальция нет; при загрязнении бикарбонатом заменить каустик известью); (4) NaHCO₃ + NaOH = Na₂CO₃ + H₂O; (5) Na₂CO₃ + Ca(OH)₂ = CaCO₃ + 2NaOH. (140–143)

Табл. 1 (137): плотность фильтрата → NaCl: 1,005 → 0,76 % мас.; 1,050 → 7,34 %; 1,100 → 14,00 %; 1,150 → 20,09 %; 1,200 → 25,68 %.
