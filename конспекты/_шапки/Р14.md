## ⭐ Формулы и примеры (всё — для задач на КР)
**Перевод единиц (453–454):** 1 bbl = 5,615 ft³ = **0,159 м³**; 1 м³ = 6,289 bbl; 1 ft³ = 0,0283 м³ = 7,48 gal; 1 gal = 3,785 л; 1 lb = 0,454 кг; 1 ft = 0,3048 м; 1 in = 2,54 см; **1 psi = 6,895 кПа = 0,0703 кгс/см²**; 1 бар = 100 кПа; **1 lb/bbl = 2,853 кг/м³**; **1 lb/gal = 119,83 кг/м³ (0,11983 г/см³)**; 1 lb/ft³ = 16,02 кг/м³.

**Ёмкости (455–456):** прямоугольная V = L·W·H, раствор L·W·M; вертикальный цилиндр **V = 0,7854·D²·H** (раствор — ×M); горизонтальный цилиндр: $V = \dfrac{L}{2}\Big[(2M-D)\sqrt{MD-M^2} + \dfrac{D^2}{2}\arcsin\Big(\dfrac{2M}{D}-1\Big) + \dfrac{\pi D^2}{4}\Big]$.

**Скважина (457):** Vскв = ΣVсекц; **Vсекц = 0,785·(K·D)²·L** (K — коэффициент кавернозности, в колонне = 1; D открытого ствола = D долота × K). **Кольцевое пространство: V = 0,785·[(K·ID)² − OD²]·L** *(прим.: в PDF напечатано (K·ID − OD)², верно — разность квадратов, ср. стр. 468)*.

**Насосы (463):** КПД (коэффициент наполнения) 85–100 %; подпорные центробежные насосы. **Триплекс** (одностороннего действия, ход 150–300 мм, 60–160 ход/мин): $Q = \dfrac{3\pi\,ID^2 L K}{4}$ за ход. **Дуплекс** (двустороннего, ход 250–450 мм, 40–80 ход/мин): $Q = \dfrac{2\pi}{4}[D^2L + (D^2L - d_0^2L_0)]K$. НБТ-600: 600 кВт, 25 МПа, 2 цилиндра, ход 400 мм; УНБ-600: поршень 200 мм → 51 л/с при 10 МПа; 140 мм → 23,3 л/с.

**Время (467):** полная циркуляция = Vактивной системы / Qнас; **подъём забойной пачки = Vзатруб / Qнас**; цикл по скважине = (Vскв − Vинстр)/Qнас; ходы = время × частота (или объём / подача за ход).
**Скорость восходящего потока (468):** S = (π/4)·[(K·ID)² − OD²]; **V = Q/S**.

**Гидростатика (468–470):** **TVD** — глубина по вертикали (от стола ротора); **MD** — по стволу. **Давления и градиенты — по TVD; объёмы — по MD.** Градиент давления — изменение давления на 1 м по вертикали, кгс/см²/м: **градиент = ρ(г/см³)/10**; ρ = 1,2 → 0,12 кгс/см²/м *(в PDF опечатка «0,52»)*. **HP (кгс/см²) = ρ·TVD/10**; пример: SG 1,439, TVD 3201 м (MD 3811) → **HP = 460,6 кгс/см²**.

**Материальный баланс (471)** — закон сохранения массы: **V = ΣVᵢ; Vρ = ΣVᵢρᵢ**. Шаги: схема → известные/неизвестные → балансы масс и объёмов → система двух уравнений. Плотности: вода 1000, бентонит **2600**, барит **4194** кг/м³.
| Пример | Дано | Ответ |
|---|---|---|
| 1. Утяжелённый раствор | 159 м³, ρ 1,92, бентонит 57 кг/м³ | Vбент = 57·159/2600 = 3,5 м³; вода 111,45 м³; барит 44 м³ = **184 536 кг**; бентонит 9100 кг |
| 2. Ингибированный солевой | 159 м³, ρ 1,678, бент. 42,8 кг/м³, Cl⁻ 150 000 мг/л | ρрассола = 1 + 1,166·10⁻⁶Cl − 8,375·10⁻¹³Cl² + 1,338·10⁻¹⁸Cl³ = **1,1605**; рассол 130,5 м³; барит 25,9 м³ (108 625 кг); пресная вода 0,913·130,5 = 119,2 м³ |
| 3. Смешивание | ρ₁ 1342, ρ₂ 1845 → 159 м³ ρ 1678 | V₁ = 52,8 ≈ **53 м³**, V₂ = 106 м³; $\rho_{кон} = \dfrac{V_1\rho_1 + V_2\rho_2}{V_1+V_2}$ |
| 4. Утяжеление | 159 м³, 1678 → 1917 | $V_{бар} = \dfrac{V(\rho_к-\rho_н)}{\rho_{ут}-\rho_к} = \dfrac{159·239}{2277}$ = **16,7 м³ = 70 040 кг**; Vкон = 175,7 м³. На 1 м³: $Q_{ут} = \rho_{ут}\dfrac{\rho_к-\rho_н}{\rho_{ут}-\rho_к}$; $V_к = V\dfrac{\rho_{ут}-\rho_н}{\rho_{ут}-\rho_к}$ *(в PDF знаменатель напечатан с ρнач — по выводу должно быть ρкон)* |
| 5. Разбавление водой | 159 м³, 1920 → 1440 | $V_в = V\dfrac{\rho_н-\rho_к}{\rho_к-\rho_в}$ = **173,5 м³**; Vкон = 332,5 м³ |
| 6. Снижение твёрдой фазы | 159 м³, ТФ 8 % → 6 %, ρ 1440 | разбавить 53 м³ суспензией (вода 47,4 м³ + барит 5,6 м³ = 23 320 кг); Vкон = 212 м³ |

**Анализ твёрдой фазы (480–486):** неутяжелённый — ЛТФ (лёгкая твёрдая фаза) ρ = 2600: **%V_ЛТФ = 100·(ρр − ρв)/(ρЛТФ − ρв)**; для 1102 → 6,4 %. Утяжелённый (ρ 1918, Cl 50 000, нефть 5 %, вода по реторте 63 %): ρрассола 1,056; %NaCl = Cl·1,65/(ρ·10⁴)·… = **7,81 %**; **Vсоль = Vвода·[100/(ρрасс·(100 − %NaCl)) − 1] = 1,69 %**; Qсоль = (Vв + Vс)·Cl·Фактор/1000 = 53,36 кг/м³; $V_{ут} = \dfrac{100\rho_р - (100 - V_в - V_с - V_н)\rho_{ЛТФ} - (V_в+V_с)\rho_{расс} - V_н\rho_н}{\rho_{ут}-\rho_{ЛТФ}}$ = **25,41 %** (1065,7 кг/м³); ЛТФ = 4,9 % (127,4 кг/м³); сумма 1918,4 ✔.
- ЛТФ = бентонит + шлам; **МВТ, кг/м³ = (мл МС / мл раствора)·14,25**; **CEC_A = 2,968·МВТ/V_ЛТФ**; CEC шлама **10**, бентонита **65**; **Vбент = V_ЛТФ·(CEC_A − 10)/(65 − 10)**; Q = V(%)·26 кг/м³. Пример МВТ 71: CEC 39,1; бентонит 2,6 % (67,6 кг/м³); шлам 2,3 % (59,8 кг/м³).
