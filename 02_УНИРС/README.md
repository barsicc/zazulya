# УНИРС по плотности бурового раствора

Подготовка расчётно-теоретической студенческой работы для варианта № 7 по дисциплине «Промывка скважин и буровые растворы». Срок сдачи 29 ноября 2026 года.

## Начало новой сессии

1. Откройте рабочую ветку `unirs-2026` и прочитайте [STATUS.md](STATUS.md). В нём указаны действующий выпуск и действия перед сдачей.
2. Проверьте [PROJECT.md](PROJECT.md) и [DECISIONS.md](DECISIONS.md), затем откройте материалы по вашей задаче из таблицы ниже.
3. Используйте [SOURCES.md](SOURCES.md) для навигации по источникам. Для повторной сверки с оригиналом пособия понадобится локальный экземпляр с указанным там SHA-256.
4. После работы обновите статус, а при изменении исходных предположений или решений — журнал решений.

Файлы ветки хранят состояние проекта и проверенные данные. Пособие получено от преподавателя и хранится локально отдельно от публичной ветки. История чатов для чтения результатов не требуется.

Для проверки расчётов используйте Python со стандартной библиотекой. Команды из корня репозитория запускают тесты и сверяют пересчитанные данные с утверждённым реестром.

```sh
python3 -B 02_УНИРС/проверка/verify_balances.py -v
python3 -B 02_УНИРС/проверка/solve_independently.py
```

Для исследовательского сценария передайте через `--input` копию [файла исходных данных](задания/ВАРИАНТ_07.json). В разделе `dilution` параметры `initial_density` и `initial_oil_volume_fraction` задают начальную плотность в кг/м³ и нефтяную долю от 0 до 1. Допустимы точные дроби в виде строки, например `"1/10"`. Цель вычисляется как начальная плотность минус `density_reduction`. Физически недостижимая альтернатива получает статус `unreachable`. Сценарий без изменения плотности получает статус `no_change`.

## Воспроизведение выпуска

Редактируйте исходные главы в каталоге [реферат](реферат/). Порядок глав при сборке соответствует [плану](реферат/ПЛАН.md). Сборка применяет настройки Word, встраивает рисунки и формулы OMML. Оглавление располагается после титула, а его номера сверяются с итоговым PDF.

Из корня репозитория выполните команды с Python, Matplotlib, Pandoc, python-docx, LibreOffice (`soffice`) и Poppler (`pdftotext`). Первые две команды нужны при повторном построении иллюстраций. Готовые PNG и SVG хранятся вместе с главами.

```sh
python3 -B 02_УНИРС/реферат/сборка/draw_abr1.py
python3 -B 02_УНИРС/реферат/сборка/plot_dilution.py --report
python3 -B 02_УНИРС/реферат/сборка/build_report.py
```

Сборка записывает Word и PDF с суффиксом `_К_СДАЧЕ`. Для сборки одного Markdown добавьте `--markdown-only`. Перед сдачей впишите ФИО на титульном листе личной копии Word. Если сдаёте PDF, экспортируйте заполненную копию и проверьте оглавление после экспорта.
